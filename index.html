START HERE

AURA user guide

What every tab does, how to use each feature, and what the prototype can actually do.

Quick start: choose a demo login → open GPS & bus map → press “Start GPS sharing” to trigger browser permission → open Face attendance → start camera → select a demo student → staff confirms the record.
⌂

1. Overview

The overview is the landing dashboard for quick status checks.

  • Summary cards count sample students, buses and attendance.
  • Google Maps preview updates after a location is obtained.
  • Fleet list shows each demo bus letter and whether GPS is live or sample data.
  • Quick buttons take you to the full map or guide.
⌖

2. GPS & bus map

GPS is the primary feature. The browser asks for permission only after a location button is pressed.

  • Choose the letter assigned to the device (A–Z).
  • “Locate this device” obtains one location fix.
  • “Start GPS sharing” watches location updates while the tab is open.
  • Google Maps shows the current coordinates; “Open in Google Maps” opens the map externally.
  • Press Stop sharing when finished.
◉

3. Face attendance

Camera-assisted computer vision, with staff verification.

  • Start camera and allow camera permission.
  • When the CV model loads, it checks for a visible face in the preview.
  • Select the matching student from the authorized demo list.
  • Staff must visually verify identity and tick the authorization checkbox.
  • Confirm to mark Present; the action is logged locally.
  • No face templates or camera images are saved by this app.
♙

4. Student directory

Manage the fictional roster.

  • Search by name or admission number.
  • Filter by class or bus letter.
  • Add, edit or delete demo students.
  • Choose any bus letter A–Z when adding a student.
  • Changes are stored only in this browser.
▥

5. Reports & exports

See counts and download demo data.

  • Class summary counts present students.
  • Bus assignment panel shows students per letter.
  • Export CSV to open the register in spreadsheet software.
  • Export JSON to back up all local demo records.
⚙

6. Settings & privacy

Review system limitations and reset sample records.

  • Download a backup before resetting.
  • GPS and camera are not started automatically.
  • Authentication is demo-only and not secure for production.
  • Real multi-device GPS needs a shared backend.
  • Real student use needs school approval, guardian consent where applicable, retention limits and secure access controls.
